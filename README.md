# Xwin – Cryptocurrency Trading Platform

A full-stack cryptocurrency platform built with **Spring Boot** (backend) and **React** (frontend).  
Where users can view real-time market data, manage portfolios, place orders, and track transactions.

---

## Features

- User authentication & authorization (JWT)
- Real-time cryptocurrency market data
- Buy / Sell orders
- Portfolio tracking
- Transaction history
- Order management (Open, Filled, Cancelled)
- Responsive React frontend
- RESTful API with Spring Boot

---

## Tech Stack

### Backend
- Java 17+
- Spring Boot
- Spring Security + JWT
- Spring Data JPA
- MySQL
- Maven etc

### Frontend
- React
- React Router
- Axios
- Tailwind CSS / Material UI
- Chart.js(for price charts) etc
